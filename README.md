# About Me:
Hi there, I'm Brandan-Lee

I'm a Software Engineering graduate based in Johannesburg, South Africa, with a focus on full-stack web and cross-platform mobile development. I enjoy building secure, offline-first applications, designing clean system architectures, and solving practical engineering problems from the ground up. I’m passionate about building practical software solutions and continuously expanding my skills across the full development stack.

Before starting university, I spent several years as a self-taught developer, which gave me strong hands-on experience with real projects and modern development tools. I later worked as a Junior Software Engineer where I built demos using Microsoft .NET and NopCommerce while collaborating with a project manager and development team.

# What I'm Working On
- **TechTrade SA:** A full-stack C2C PC hardware marketplace built with React, Vite, Tailwind CSS, DaisyUI, Node.js with Express, and PostgreSQL—featuring automated hardware compatibility checks, structured negotiation workflows, an escrow state machine, and role-based admin controls.
- **SaferMzansi:** A cross-platform personal safety mobile application built with React Native (Expo), Node.js, and PostgreSQL—featuring offline-first encrypted storage (AES-256), spatial routing, and stealth emergency triggers.
- **Cloud & Mobile Architecture:** Exploring cloud-native backend patterns, spatial indexing, and modular full-stack design.
- **Education:** BSc IT (Software Engineering) graduate
